# Bundled yellow Tieba faces

Source: <https://github.com/microlong666/Tieba_mobile_emotions>

Pinned source revision: `3492cf674c7596773d572708e5681603839c4b9b`.

The upstream README describes these PNGs as extracted from Baidu Tieba mobile
11.6.8.2 (2020-07-13) and documents saving the images for use. The repository
contains no separate license declaration. This provenance records the source;
it does not grant additional rights or place these images under the theme's license.
Original artwork belongs to its respective rights holders.

This theme bundles 54 unmodified PNGs from the round yellow face series:
1–33 excluding 6, 16 and 31; 66–76; 85–93; 95–98. Source filenames are retained
(the first face is `image_emoticon.png`). Red faces, panda faces, objects,
standalone gestures and 3D characters are excluded. The same fixed-size circular
presentation and collision geometry apply to every selected image.

The images are served from the theme's own assets. Selecting or interacting with
an emotion does not request images from GitHub or a third-party image CDN.
