# Hanlo Theme 2.7.0

本版用 OpenCC 词组词典替换旧式逐字简繁转换，并提前启动 Vditor 绘图，改善图表切换与加载。适用于 Halo 2.26.0 及以上版本。

## 简繁转换

- 引入本地按需加载的 opencc-js 1.4.2；采用 `cn → tw` / `tw → cn`，不启用台湾词汇替换模式。
- 始终从保存的原文转换，同页切回原始字形直接还原原文，避免多次转换损坏有歧义文字。
- 保护普通代码、公式、表单值、可编辑内容及 `translate="no"`、`.notranslate`、`.ignore-opencc` 区域。
- 同步动态文字、目录、图片替代文本和无障碍标签；URL 和标题锚点保持不变。
- PlantUML 从原始源码更新在线 SVG 请求，无需刷新整页；图像显示仍需等待远程服务响应。
- Mermaid、ECharts、mindmap、Graphviz 等接入统一转换状态；ECharts JSON 的字段键与对应引用保持一致。

## 绘图加载与资源

- 正文 DOM 和插件接口就绪后即启动绘图，不再等待整页图片、媒体完成 load。
- 为本篇实际需要的绘图域名提前建立连接。
- 各图独立等待与更新，慢图不再阻塞其它已就绪图表；减少无关 DOM 变化造成的重复扫描。
- Graphviz 语言重绘完成或离页时释放工作线程与临时 URL。
- OpenCC 词典不进入默认首屏依赖；安装包较 2.6.1 增加约 0.48 MiB。

## 升级与已知问题

下载 `theme-hanlo-2.7.0.zip` 更新，校验文件为 `.zip.sha256`。无需改写文章源码。实际加速幅度取决于网络和图形复杂度。

这是历史版本补发，建议安装 **2.7.2**。本版 Markmap 因插件替换节点而无法可靠同步简繁；代码亮色背景、版权缺字问题仍存在。后续 2.7.1 修复样式与节点跟踪，2.7.2 进一步修复 Markmap 捆绑 Prism 的自动扫描冲突。

## 验证与版本来源

201 项单元测试、17 项设置测试、类型与样式检查通过；按需词典和 519 个打包模板/资源完成核验。

本 Release 保留开发时的原始安装包。中间源码当时未独立提交，标签保存安装包内运行文件快照；完整可维护源码见 2.7.2。补发重新校验 ZIP、manifest、SHA-256 和标签快照内容。
