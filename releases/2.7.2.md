# Hanlo Theme 2.7.2

本版修复 Markmap 显示为 CSS 和节点文字的问题，并正式接入 Halo 应用市场自动发布。适用于 Halo 2.26.0 及以上版本。

## Markmap 修复

- 确认 Vditor 提供的 Markmap 整包脚本内包含 Prism；它加载后会自动扫描整页代码块，覆盖已经渲染的 Markmap SVG，并可能破坏旁边 Shiki 的行号与配色。
- 主题在脚本执行前设置 `data-manual`，阻止这次自动扫描，保留 Markmap 图形和 Shiki 标记。
- 重复绘图调用去重，并始终使用保存的 Markdown，不再把 SVG 的样式与节点文字当成新源码。
- 保留同一 Markmap 实例的简繁往返更新与离页清理。

## 累计功能与升级

从 2.5.0 更新可获得 Vditor 亮暗适配、Shiki 全部 242 种语言按需加载、统一纯文本代码框、本地 OpenCC 简繁转换，以及绘图提前启动与独立更新。代码块亮色背景和版权图标修复继续保留。

下载 **`theme-hanlo-2.7.2.zip`** 更新主题；`.zip.sha256` 用于校验。刷新原文章即可，无需修改 Vditor 源码或重新设置代码配色。不要使用 GitHub 自动生成的 Source code 压缩包安装。

Markmap 和其它绘图仍依赖插件配置的可用资源地址；PlantUML 在线 SVG 的返回速度取决于远程服务。完整语法和测试文章见仓库 `docs/vditor-writing.md`、`docs/examples/vditor-render-demo.md`。
