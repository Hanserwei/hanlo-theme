# Hanlo Theme 2.7.7

本版修复配置与内容渲染边界、评论和推荐文章的数据判断，并清理重复配置、模板和失效样式。适用于 **Halo 2.26.0 及以上版本**，升级保留已有主题设置。

## 修复

- 动态配置统一使用 Thymeleaf 的 JavaScript 安全序列化，名称、链接中的引号和换行不会再破坏初始化脚本。
- 自定义内容组件正确编码文本与属性，限制链接和 PDF 地址的协议；图片、视频继续支持对应用途的合法 data/blob 地址，保留富文本内容。
- 目录、图库、二维码、封面取色和播放器独立加载；可选资源失败不再撤销核心交互事件或阻塞后续功能。
- 随机文章使用 Halo 的随机查询接口，取消每页重复获取全部文章。
- 最近评论页、中控台和侧栏共用目标解析，使用精确标识，正确处理已删除文章、已删除页面、图库虚拟主体和插件停用；不可用目标显示状态并移除链接。
- 推荐文章按 `metadata.name` 排除当前文章，同名文章仍可推荐；两篇与六篇布局共用展示模板。
- 朋友圈明确搜索、排序、作者列表和更新统计的已加载范围；后续页尚未加载时，不再暗示全站没有匹配结果。重试和加载更多共用加载锁，旧请求不会更新卸载后的视图，非法链接显示为文本。
- 友链和相册增加插件可用性保护；相册分组结果只查询一次。

## 清理与资源加载

- 删除重复的 AI 配置结构、逐字段适配和无消费者参数，沿用现有配置类型。
- 清理失效导航间距、移动端卡片高度覆盖和重复 CSS 声明，将重复检查豁免缩小到具体遗留文件。
- 关于页专用样式合并为一个按页加载的入口，共用横幅和卡片基础规则继续共享。
- 六种完整字体改为 **100 个按需分片**，正文常用字首片从约 **8.02 MB 降至 1.17 MB**；保留全部源 Unicode 字符、字重、斜体、Nerd 图标和常见代码连字。字体地址包含内容哈希，独立菜单图标目录使用同一套声明。
- 本版未增加依赖，源码与 `templates/` 构建产物同步交付。

## 升级与验证范围

- 下载 **`theme-hanlo-2.7.7.zip`** 安装，使用 **`theme-hanlo-2.7.7.zip.sha256`** 校验。GitHub 自动生成的 Source code 压缩包不作为主题安装包使用。
- 自定义脚本若读取内部配置别名，应改用当前字段：`source.postAi` 改为 `postAi`，图片懒加载读取 `lazyload.enable`；已删除无消费者的 `postTitle`、`isPost`、`isHome`、`lightbox`、`translateDelay` 等字段。主题设置本身无需迁移。
- 分片保留完整字符覆盖，字体总资源从约 **43.3 MB 增至 49.2 MB**；浏览器按实际字符加载。跨分片字符的特殊组合排版仍可能受到浏览器字形塑形限制。
- 已通过类型、格式、样式和设置检查、244 项单元测试、17 项设置测试、2 项真实 Markmap 脚本测试及构建产物校验；关键模板另经 Thymeleaf 和响应式 Finder 场景验证。
- 未启动真实 Halo 实例进行本次全站联调；实际插件组合和浏览器视觉表现仍需站点验收。正式发布结果以该版本 GitHub Actions 记录和附件为准。
