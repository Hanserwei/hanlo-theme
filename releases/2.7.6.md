# Hanlo Theme 2.7.6

本版更新前端运行库与开发工具，并修复新版构建器的 Thymeleaf 模板兼容问题。适用于 **Halo 2.26.0 及以上版本**，升级保留已有主题设置。

## 运行库更新

- Three.js 从 r160 升级至 **r187（0.187.0）**，同步按需 CDN、版本校验、材质回归测试及许可声明。
- Typed.js 升级至 **3.0.0**，Shiki 升级至 **4.6.0**；更新点击特效、GSAP、Swiper、HLS 和正文解析依赖。
- Markmap 缺省资源升级至 **Vditor 4.0.1**，继续优先使用插件提供的 CDN。保留手动加载、同一图形的简繁更新与离页清理。
- 清理已有标准 `opacity` 样式覆盖的过时 IE 透明滤镜，更新第三方声明和生成资源。

## 构建与发布

- 开发和 CI 使用 **Node.js 26 LTS / pnpm 12.21.0**；本地构建最低支持 Node.js 24.15.0。
- 升级 TypeScript **7.0.2**、Vite Plus **1.6.0**、Vitest **5.1.0**、Tailwind CSS **4.3.5** 和 Stylelint **18.0.0**。
- Vite 使用 Vite Plus 配套内核 **8.3.7**，统一构建和测试依赖；修复入口合并导致 Thymeleaf 条件被当作 CSS 解析的问题，继续原样输出 Halo 模板。
- 修复依赖摘要偶然包含旧导航库名称时触发的校验误报，并增加回归测试。
- 更新 GitHub Actions；pnpm 版本从检出源码的 `packageManager` 读取，兼容旧标签发布重试。
- Halo 开发镜像更新至 **2.27.3**，主题最低兼容版本保持 2.26.0。

## 验证与已知限制

- 静态检查、227 项单元测试、17 项设置测试、2 项真实 Markmap 脚本测试和主题构建通过；安装包经过 ZIP、manifest 与 SHA-256 校验。
- 已在 Chromium 验证 Three.js 实际 CDN 加载、桌面和手机尺寸渲染、风暴切换、重置及资源清理，以及 Typed.js 动画。
- 3D 关于页需要 **WebGL2**；资源或渲染器不可用时显示重试提示并回退到可阅读的文字内容。
- 本次依赖审计仍报告 **33 项上游告警（含 12 项高危）**，涉及 DPlayer 与打包工具固定的 `axios`、`glob`、`minimatch` 依赖。
- 未启动 Halo 容器进行本版联调；实际设备的图形性能仍需站点所有者验收。
