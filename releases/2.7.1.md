# Hanlo Theme 2.7.1

本版修复代码块浅色背景和版权装饰缺字，并改进 Markmap 节点跟踪。适用于 Halo 2.26.0 及以上版本。

## 修复

- 移除将所有代码块强制设为深色背景的遗留 CSS。One Light / One Dark Pro 等配置的背景与文字同步生效。
- 修正版权装饰图标的字体来源，使用随主题提供的 haofont；解决繁体模式下出现缺字方框的问题。
- Markmap 改为稳定节点上的实例更新，避免原插件删除 CODE 节点后丢失简繁切换跟踪；增加实例释放与布局完成等待。
- 增加覆盖完整样式层级、三组代码配色、简繁与亮暗模式的回归检查，并验证打包字体确有版权字形。

## 升级与已知问题

下载 `theme-hanlo-2.7.1.zip` 更新，`.zip.sha256` 可用于校验。无需调整已经设置好的代码配色。

这是历史版本补发。代码背景与版权图标修复已通过用户实机确认，但此版仍受 Markmap 脚本内捆绑 Prism 自动扫描的影响：图形可能被替换为样式和节点文字。请优先安装已修复此问题的 **2.7.2**。

## 验证与版本来源

209 项单元测试、17 项设置测试、类型与样式检查通过；519 个模板和资源与 ZIP 一致，实际 WOFF2 的 U+E668 对应版权图标。

此 Release 使用当时保存的原始安装包，未以新版代码重建。中间源码当时未独立提交，标签保留安装包内的运行文件快照；完整可维护源码见 2.7.2。补发重新校验 ZIP、manifest、SHA-256 和标签快照内容。
