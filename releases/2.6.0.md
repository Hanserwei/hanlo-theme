# Hanlo Theme 2.6.0

本版增加 Vditor 文章的亮暗模式适配，并将 Shiki 扩展为全部内置语言按需加载。适用于 Halo 2.26.0 及以上版本。

## 新增与改进

- 同步主题与 Vditor 的亮暗状态，切换时从保存的源码重新渲染 Mermaid、ECharts 和脑图。
- 修复 Mermaid 中文标签受正文段落间距影响的问题；宽图保留可读尺寸并允许横向滚动，ECharts 随容器宽度调整。
- 五线谱谱线跟随正文颜色；Graphviz 保留 DOT 自身填充色，避免插件暗色样式统一覆盖。
- Graphviz、旧式 Flowchart 和远程 PlantUML 使用浅色画布，保留作者指定的配色。
- Shiki 4.4.3 开放 242 种语言和 104 个官方别名，语法资源随主题提供并按文章需要加载；正则引擎采用 Oniguruma。
- XML 使用独立语法；图表和公式围栏交给 Vditor，避免被普通代码高亮替换。

## 升级与已知问题

下载 `theme-hanlo-2.6.0.zip` 安装，`.zip.sha256` 用于校验。安装包约 45.01 MiB，增加的语言文件不会在每篇文章中全部下载。

这是历史版本补发，建议日常使用更新的 **2.7.2**。本版仍有纯文本围栏缺少代码框、代码末尾额外空行、部分简繁图表不同步，以及遗留样式覆盖代码亮色背景的问题；后续版本分别修复。Vditor 渲染资源与插件方法包应使用匹配版本，PlantUML 仍依赖在线服务。

## 验证与版本来源

当时的类型、格式、CSS 检查，176 项单元测试、17 项设置测试及构建通过；全部 242 种 Shiki 语法完成加载与高亮测试。

此 Release 使用开发时保存的原始安装包，未以新版本源码重新构建。由于当时未单独提交中间源码，Git 标签保存安装包内的运行文件快照；完整可维护源码见 2.7.2。补发时重新核验 ZIP、manifest、SHA-256 和标签快照内容。
