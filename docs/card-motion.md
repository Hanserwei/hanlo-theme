# 卡片光晕与呼吸效果

文章卡片沿用原有的悬停擦亮效果；描边增加两段顺着圆角缓慢移动的主题色高光，并辅以柔和的内外光晕。支持键盘操作的卡片在获得可见焦点时也有边缘提示。

卡片平时只在边缘产生低强度明暗变化，约 6.4–8.5 秒一个周期，相邻卡片错开相位。卡片尺寸、文字与布局保持稳定。触屏使用更慢、更轻的 9 秒呼吸，不触发鼠标专用的流光循环。

当前覆盖文章列表及推荐卡片、普通侧栏卡片、关于页卡片、主题友链卡片、最近评论卡片、相册卡片及朋友圈文章卡片。音乐、Steam 翻转卡片和分类 3D 卡片保持各自的专用交互。

## 加载与性能

- 使用原生 CSS 渐变、遮罩及透明度动画，没有新增动效依赖。
- `src/js/features/card-motion/index.ts` 由统一页面生命周期挂载；为每张最外层卡片添加一个不接收鼠标事件、读屏隐藏的装饰节点。
- IntersectionObserver 控制离屏暂停；页面隐藏或进入历史缓存时暂停，返回时恢复。
- MutationObserver 支持异步出现的卡片，并清理被移除卡片的引用；页面销毁时移除装饰节点和观察器。
- 遵循系统“减少动态效果”设置；停用循环动画，保留静态交互提示。
- 光晕读取 `--heo-main`，随主题明暗模式和强调色变化；不支持遮罩合成的浏览器退回静态细线。

样式位于 `src/css/overrides/card-motion.css`。原文章擦亮样式 `src/css/pages/home-post-list.css` 未改动。

## 验证

生命周期测试覆盖嵌套卡片去重、相位错开、离屏及后台暂停、减少动态效果、异步插入和移除清理。构建后在独立预览中检查桌面明暗模式、390px 窄屏、文章 hover 时的尺寸稳定与链接命中，以及关于页卡片布局。实际主题安装与最终手感可在更新安装包后确认。
