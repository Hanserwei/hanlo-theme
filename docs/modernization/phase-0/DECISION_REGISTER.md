# 阶段 0 决策登记表

## 1. 状态规则

| 状态 | 含义 |
| --- | --- |
| 待确认 | 已提出，尚未由维护者选择 |
| 已接受 | 可以据此安排实现或删除 |
| 已拒绝 | 明确不采用提案，记录替代结论 |
| 已替代 | 后续决策取代了本决策，需指向新编号 |

所有删除动作必须引用“已接受”决策。已接受结论由维护者于 2026-08-31 确认；仍为“待确认”的项目不得顺带处理。

## 2. 必须在删除前确认的决策

### P0-DEC-001：Halo 最低版本

- **状态**：已接受
- **结论**：主题最低版本调整为 Halo `>= 2.26.0`。
- **影响**：决定安装验证环境、Finder/API 能力和后续工具链兼容范围。
- **维护者答复**：只支持 Halo 2.26.0 及以上版本。

### P0-DEC-002：浏览器范围

- **状态**：已接受
- **兼容矩阵**：
  - 桌面 Web：Chrome/Chromium 当前稳定版及前一个大版本。
  - 手机 Web：Android Chrome/Chromium 当前稳定版及前一个大版本。
  - 不纳入支持范围：Firefox、Safari、iOS Safari、微信内置浏览器和其他非 Chromium WebView。
- **依据**：当前样式已使用 `:has()`，全局脚本使用 ES Module、可选链、`IntersectionObserver` 等现代能力。
- **影响**：阶段 0 只使用桌面 Chrome/Chromium 和 Android Chrome/Chromium 视口验收，不为非 Chromium 浏览器引入 polyfill。
- **维护者答复**：只考虑 Web 和手机端的 Chrome 内核浏览器兼容。

### P0-DEC-003：广告能力

- **状态**：已接受
- **范围**：Google AdSense、自定义广告、侧栏 `adbox` 候选项。
- **结论**：全部删除。
- **预计删除**：`settings.yaml` 中五类页面侧栏的 `adbox` 候选、`sidebar.adbox` 配置、`aside/adbox.html` 及专属说明。
- **维护者答复**：Google AdSense 和自定义广告全部删除。

### P0-DEC-004：侧栏爱发电

- **状态**：已接受
- **范围**：侧栏 `power` 组件、爱发电列表加载、爱发电专属图片和配置。
- **结论**：全部删除。
- **注意**：不等同于文章/关于页的微信、支付宝打赏。
- **维护者答复**：爱发电相关能力全部删除。

### P0-DEC-005：文章和关于页打赏

- **状态**：已接受
- **范围**：文章页打赏按钮、微信/支付宝二维码、关于页赞赏名单。
- **结论**：保留为可选能力；“爱发电全部删除”只处理 P0-DEC-004 的爱发电实现。
- **注意**：必须与 P0-DEC-004 分开选择。
- **维护者答复**：维护者说明删除微信公众号组件和 51LA、其余能力保留，因此直接打赏不在删除范围。

### P0-DEC-006：微信公众号组件

- **状态**：已接受
- **范围**：侧栏公众号卡片、背景/正反面图片和跳转地址。
- **结论**：全部删除。
- **维护者答复**：微信公众号组件删除。

### P0-DEC-007：开往

- **状态**：已接受
- **当前状态**：导航默认开启，跳转到 `travellings.cn`。
- **结论**：保留为可选功能。
- **维护者答复**：开往属于需要保留的友链/前往能力。

### P0-DEC-008：51LA 统计

- **状态**：已接受
- **范围**：全站统计脚本和关于页统计卡中的 51LA 请求。
- **结论**：全部删除。
- **维护者答复**：删除 51LA。

### P0-DEC-009：音乐能力

- **状态**：已接受
- **结论**：只保留侧栏音乐卡片：

| 子项 | 当前实现 | 建议 |
| --- | --- | --- |
| 音乐馆页面 | `music.html` + APlayer/Meting | 删除 |
| 左下角导航播放器 | `nav-music.html`，默认关闭 | 删除 |
| 侧栏音乐卡片 | 外部图片卡片服务 | 保留 |

- **影响**：侧栏音乐卡片只显示外部卡片图片，不依赖 APlayer/Meting；音乐馆和导航播放器删除后应一并移除 APlayer、Meting 资源及全站加载。
- **维护者答复**：只保留侧栏音乐卡片。

### P0-DEC-010：3D 分类

- **状态**：已接受
- **当前状态**：默认关闭；启用后加载 `no3d` 和单独的 Vue 2 副本。
- **结论**：保留 3D 分类模式。
- **影响**：阶段 0 不删除 `no3d` 和其 Vue 2 副本；阶段 4 再治理依赖来源和加载范围。
- **维护者答复**：除明确删除项外其余保留。

### P0-DEC-011：自定义右键菜单

- **状态**：已接受
- **当前状态**：默认关闭；依赖 jQuery 和多个全局对象。
- **结论**：保留为可选功能。
- **影响**：删除外部评论和导航音乐时，只清理右键菜单中对应的评论/播放器操作，保留通用菜单能力。
- **维护者答复**：除明确删除项外其余保留。

### P0-DEC-012：评论系统收敛

- **状态**：已接受
- **当前实现**：Halo `plugin-comment-widget`、Twikoo、Artalk、Waline。
- **结论**：只保留 Halo 原生 `plugin-comment-widget`；删除 Twikoo、Artalk、Waline。
- **影响**：评论模板、最近评论、弹幕、匿名邮箱、vendor 资源和多处分支逻辑。
- **维护者答复**：只保留对 Halo 原生评论的支持。

### P0-DEC-013：群聊和“推广”定义

- **状态**：已接受
- **澄清**：“群聊和推广”指友链及开往/前往能力，不是独立的群聊模块。
- **结论**：保留友链页面、友链插件集成、互动友链和开往入口。
- **影响**：阶段 0 不删除 `plugin-links` 集成、友链模板、开往设置与脚本。
- **维护者答复**：友链和前往功能需要插件支持，保留。

### P0-DEC-015：截图证据存储

- **状态**：已接受
- **选项 A**：将优化后的 WebP/JPEG 和清单提交到 `docs/modernization/phase-0/evidence/`，审阅直观但会增加仓库体积。

- **维护者答复**：同意选项 A；阶段 0 截图随 Git 保存到 `docs/modernization/phase-0/evidence/`。
