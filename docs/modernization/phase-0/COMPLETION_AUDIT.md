## 5. 仍需跟踪的问题

这些不是阶段 0 阻塞项，但后续阶段不能遗忘：

1. Halo 报告 `MissingLayoutTemplate`，主题尚未提供插件页面布局契约。
2. Fancybox CSS 使用 `/null` 占位，桌面页面产生 404。
3. 快速 PJAX 导航时 Typed.js 可能访问已离开页面节点；阶段 2 统一生命周期处理。
4. 首页冷加载图片约 21.57 MB，外部资源较多；阶段 4/6 做按需加载和性能预算。
5. Shiki 在文章页产生大量运行时脚本请求；阶段 4 改为本地按语言和主题打包。
6. `.env.local` 当前文件权限为 `0644`，建议维护者调整为 `0600`。
