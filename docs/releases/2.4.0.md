# Hanlo Theme 2.4.0

本版为关于页和分类页加入新的交互效果，完善全站卡片光影，并修复关于页布局。适用于 Halo 2.26.0 及以上版本。

## 新增与改进

- **黄色表情互动区**：关于页原问候横幅改为物理表情区域，内置 54 款黄色圆脸 PNG。支持拖拽、抛掷、碰撞和堆叠，统一 56px 圆形；后台可预览多选并设置总数，默认 24 个，可选 1–48 个。
- **手机运动感应**：访客主动开启并授权后，倾斜和晃动手机可影响表情。需要 HTTPS 和浏览器支持，无法使用感应时仍可拖动或点击“摇一摇”。
- **蔚蓝档案点击特效**：集成 ba-click-fx，点击出现光环与碎片，按住拖动显示光尾。在「全站外观」提供开关，默认开启，关闭后不加载特效模块。
- **卡片流光与呼吸**：保留文章 hover 擦亮效果，新增沿圆角移动的柔光描边；文章、普通侧栏、关于页等卡片增加轻微错相呼吸，离屏及后台暂停。
- **3D 分类页重做**：使用 GSAP 提供逐张入场、卡面抬升、指针分层视差和按压反馈。六组配色搭配悬浮立方体、双层光环与网格背景，未配置封面也有完整视觉；名称、简介和文章数始终可见。
- **关于页布局修复**：居住地与个人信息铺满整行；未配置地图与居住地时不显示空卡片；单张地图支持明暗共用；个人信息桌面三列、窄屏竖排，长文字正常换行并改善文字对比度。

## 升级说明

- 下载本页附件 **`theme-hanlo-2.4.0.zip`** 更新主题。GitHub 自动生成的 Source code 压缩包不是安装包。
- 原关于页 `hello-about` 区块标识及排序继续使用，旧问候语 `about.helloAbout` 不再生效；已有站点未配置新表情字段时采用默认值。
- 分类集合页原 `3D` 配置直接启用新版视觉，普通分类列表保持原样。
- 动效遵循系统“减少动态效果”；触屏分类页采用较轻的动画。资源随主题提供，第三方许可和表情来源包含在安装包中。
