# Hanlo Theme 2.5.0

本版新增「瓶中沧海」3D 关于页，支持与原文字关于页切换；同时修复评论昵称、头像和 HTML 标签显示，改进页面加载与入场动画。适用于 Halo 2.26.0 及以上版本。

## 瓶中沧海

- **宽屏场景**：玻璃瓶、木托架、木桌、旧书和黄铜望远镜融入站点背景。透明画布铺满导航下方的可用空间，没有房间墙板、窗框及圆角卡片底板；镜头按瓶体轮廓适配宽屏和手机。
- **微缩海洋**：体素海面在 GPU 上起伏，浪尖出现零散泡沫；连续渐变深水体内有发光宝箱、沉锚、双耳瓶、珊瑚与上升气泡。
- **航行与生物**：三桅方帆船、红纹主帆和索具，四点波高采样驱动升沉与摇摆；岛上有旋转光束灯塔、棕榈、暖窗小屋、码头和小艇，海鸥、积云、鲸鱼、鱼群、浮标和螃蟹点缀其间。
- **风暴与昼夜**：拖动环视、滚轮或双指缩放，闲置自动环航。聚焦场景后按住 Space，或按住风暴按钮，触发浪涌、飞沫、闪电、乌云和瓶身摇晃。时间支持 ×1、×4、×12、暂停，并驱动黎明、正午、黄昏与子夜变化。
- **航海手记**：点击吊牌、帆船、灯塔、宝箱、望远镜或书本读取现有介绍、经历、想法、爱好及建站故事。手记默认收起，页底章节按钮提供相同入口。
- **光影修复**：实例颜色正确参与渲染，船体、灯塔和木桌不再被错误乘黑；玻璃与水体统一色调映射和输出色彩，玻璃高光跟随场景光源方向。

## 评论与加载体验

- 中控台显示评论者真实昵称，移除固定的 `stonewu` 文本。
- 中控台、侧栏和最近评论页共用头像规则：已有头像优先，缺失时使用邮箱哈希头像；无哈希或远程失败时生成稳定的本地彩色头像。
- 中控台接入安全的纯文本评论摘要，处理 HTML 标签、实体和图片说明，不执行评论 HTML 或加载其嵌入资源。
- 加载页加入头像轻浮动、环绕光点、光晕、跳点和流动光条，完成后首屏内容错落淡入。统一关闭入口，避免重复播放，并修复减少动态效果下的退场。

## 升级说明

- 下载本页附件 **`theme-hanlo-2.5.0.zip`** 更新主题，`.zip.sha256` 用于校验。GitHub 自动生成的 Source code 压缩包不是主题安装包。
- 在「主题设置 → 关于页面 → 默认展示方式」选择瓶中世界或文字关于。旧设置缺少该字段时默认启用瓶中世界；访客可在页顶切换，选择在当前浏览器会话记忆。
- 两种关于页共用现有配置，已关闭的内容区块继续遵循原设置。文字关于保留完整资料、照片、统计及表情互动；切换或 3D 加载失败后恢复正常阅读宽度。
- Three.js 固定为 r160，仅进入 3D 模式时从 jsDelivr CDN 加载。WebGL 不可用、CDN 超时或上下文丢失时恢复文字内容并提供重试入口。
- 系统开启「减少动态效果」时场景默认暂停并关闭风暴。后台、离屏及文字模式暂停渲染，离开页面释放资源。
- 渲染分辨率随帧耗时调整，并受 360 万像素预算限制。60FPS 是优化目标，实际帧率取决于设备与浏览器。

## 验证

- `pnpm check`、`pnpm test`、`pnpm build` 通过，共 184 项测试。
- 18 个着色器阶段通过固定 r160 的离线 GLSL 编译；真实模型检查覆盖颜色属性、几何与动画矩阵。
- 验证宽屏/手机相机投影、模式切换、失败降级、BFCache、可见性与资源释放；Thymeleaf 渲染覆盖两种模式、旧配置及空内容。
- 光影修复使用构建产物检查黄昏、子夜及风暴渲染；最终宽屏透明布局和实机帧率由安装后的视觉验收确认。

完整操作与内容映射见仓库中的 [瓶中沧海说明](https://github.com/Hanserwei/hanlo-theme/blob/2.5.0/docs/about-bottle.md)。
