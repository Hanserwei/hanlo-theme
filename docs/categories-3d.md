# 分类页立体探索卡片

在「主题设置 → 分类集合页 → 分类集合页布局」选择「立体探索卡片（3D 动效）」。原 `3D` 配置值继续生效，分类名称与文章数列表模式保持原有显示。

## 视觉与交互

- 六组循环配色、透明立方体、双层光环、微光粒子和网格背景，无分类封面时也有完整视觉。
- 分类名称、简介和文章数量始终展示，整张卡片是可访问的分类链接；没有简介时提供简短默认文字。
- 卡片进入视口时错开入场。桌面端几何核心轻轻浮动、旋转，双层光环以不同节奏运动。
- 鼠标悬停抬升卡面，指针位置控制倾斜、背景与文字视差及聚光位置；扫光短暂掠过卡面，移开后平滑归位。
- 点击时有轻微按压反馈。键盘 Tab 聚焦可立即显示该卡片，并提供清楚的焦点描边。
- 触屏保留入场和点击反馈，停用持续浮动和鼠标倾斜，页面可以正常滚动。

分类封面可选，仍在 Halo 的「文章 → 分类」维护。图片作为淡化背景与几何效果融合；空封面不输出图片，加载失败时回退到几何背景。封面建议 1:1、至少 640×640 像素。

## 动画与性能

采用固定版本 `gsap@3.15.0`。只在存在 3D 分类卡片且系统允许动态效果时加载独立场景文件，普通分类列表和其他页面不会加载 GSAP 场景。

每张卡片独立监听可见性，离屏和页面隐藏时暂停动画；浏览器历史缓存恢复后继续。启用系统“减少动态效果”时清理动画并恢复静态 CSS；关闭该偏好可重新创建场景。下载中的模块会检查页面是否已销毁。

GSAP context 负责撤销变换和动画，PageResourceScope 管理观察器与事件。动效使用 `quickTo` 复用缓动实例，避免每次指针移动都新增独立动画。

## 实现与验证

- 模板：`src/categories.html`
- 页面专用样式：`src/css/pages/categories-3d.css`
- 加载和指针计算：`src/js/features/categories-3d/index.ts`、`geometry.ts`
- GSAP 场景：`src/js/features/categories-3d/scene.ts`

离线 Thymeleaf 渲染验证覆盖无图、有图、无简介、长标题和空分类；独立浏览器预览使用实际构建资源，检查明暗模式、390px 窄屏、图片失败回退、hover 视差与链接命中、后台暂停及销毁清理。减少动态效果通过单元测试及显式偏好模拟验证，最终安装效果留给实机确认。
