# 瓶中沧海 · 3D 关于页

关于页面现在提供「瓶中世界」和「文字关于」两种展示。主题设置 → 关于页面 → 默认展示方式可修改首次打开的模式；访客在页顶切换后，选择会保存在当前浏览器会话中。旧配置缺少该字段时默认打开瓶中世界。现有个人资料和经典区块均保留。

瓶中世界铺满导航下方的页面宽度和可视高度，透明画布直接融入站点背景。场景保留木桌与陈设，移除房间墙板和窗框；首屏手记默认收起，选中场景或章节后再打开。切回文字关于或 3D 加载失败时恢复正常阅读宽度。

## 操作

- 鼠标或单指拖动环视；滚轮或双指缩放；闲置 7 秒后缓慢自动环航。
- 聚焦场景后按住 Space，或按住「风暴」按钮，增强风浪、飞沫、乌云、闪电和瓶体摇晃；松开后缓慢恢复。
- 「时间」循环切换 ×1、×4、×12、暂停。昼夜、船、生物、波浪和风暴使用同一时间轴；暂停时仍可拖动查看和阅读手记。
- 系统开启「减少动态效果」时默认暂停，并关闭风暴；可主动切换时间倍速继续播放。
- 点击瓶颈吊牌、帆船、灯塔岛、宝箱、望远镜或旧书打开手记。页底章节按钮提供同样入口，键盘用户可直接操作。Esc 收起手记。

## 实现与边界

Three.js 固定使用 `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js`，仅进入瓶中世界才请求。本地开发依赖中的 r160 和类型声明用于场景回归测试，生产运行时仍按需从 CDN 加载，不把 Three.js 打进公共入口。CDN 超时、WebGL 初始化失败或上下文丢失时显示重试提示并恢复可阅读的经典内容。

场景包含横卧玻璃瓶、塞与蜡封、绳与吊牌、木托架、桌面、书与望远镜；瓶内包含 GPU 位移体素海面、连续渐变深水体、四点采样浮力帆船、索具、灯塔岛、暖窗小屋、棕榈、码头小艇、水下宝箱/沉锚/双耳瓶/珊瑚、气泡、海鸥、积云、鲸鱼、浮标、鱼和螃蟹。内部材质通过逆瓶体矩阵和轴向半径函数裁剪，瓶身摇晃时海洋仍位于世界坐标，保持平均水面水平。

默认相机按玻璃瓶轮廓和瓶塞计算取景距离，适配横竖屏并留出标题、章节控件空间；重置视角会重新计算，缩放范围随画布尺寸变化。画布聚焦时在控制条显示键盘焦点提示。

体素合并为 InstancedMesh；GPU 波形和船体采样共用同一数学模型。按滚动可见性、文档可见性、展示模式和 BFCache 生命周期暂停渲染。像素倍率依据帧耗时调整，最高为 1.6，同时受设备像素比和 360 万渲染像素预算限制，避免铺满超宽屏后渲染开销失控。60FPS 是性能目标，不是所有设备的帧率保证；移动端、大屏和低功耗 GPU 需要实际设备验收。

页面销毁时取消动画帧和监听器，断开观察器，释放实例、几何体、材质、渲染器和 WebGL 上下文。Three.js MIT 许可已纳入主题第三方声明。

## 验证

- 单元测试覆盖瓶形边界、浮力和船向、风浪幅度、倍速、暂停、分辨率限幅、宽屏/手机镜头投影，以及 CDN 延迟/失败、展示切换和清理。
- 实际构建所有模型并检查材质与颜色属性：体素使用 `instanceColor`，不能在缺少几何体 `color` 属性时启用 `vertexColors`，否则模型会被乘黑且不一定报错。自定义玻璃和水体输出需包含 Three.js 的色调映射和输出色彩转换。
- 可在不启动浏览器的条件下，用固定 r160 ShaderLib 展开自定义 shader，再由 GLSL 编译器检查顶点和片段阶段；创建模型并遍历矩阵检查非有限坐标。
- 离线 SpringTemplateEngine 验证两种模式、旧设置缺少展示字段和内容为空的渲染。
- 浏览器视觉及实机帧率由站点所有者验收。
